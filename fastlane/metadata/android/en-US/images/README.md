# Fastlane Store Graphics Guidelines (F-Droid / IzzyOnDroid)

- **`icon.png`**: `512x512` PNG (32-bit RGBA, <= 1 MB). Generated from `assets/sonata-logo.svg`.
- **`featureGraphic.png`** *(optional)*: `1024x500` PNG or JPEG (no alpha channel recommended).
- **`phoneScreenshots/`**: Up to 8 PNG/JPEG screenshots (`1.png`, `2.png`, ...), minimum `320px` on the shortest side, maximum `3840px` on the longest side, aspect ratio between `16:9` and `9:16`.
- **`tenInchScreenshots/`** *(optional)*: Tablet screenshots following the same naming convention (`1.png`, `2.png`, ...).
